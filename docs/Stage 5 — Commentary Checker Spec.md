## Design decisions (confirm before writing the checker)

| # | Decision | Proposal |
|---|---|---|
| D1 | API in tests | A **fake client** returns canned JSON fixtures. The checker makes no network calls. A real call happens only in `scripts/demo_commentary.py`, which is not part of the checker. |
| D2 | Model and key | The model comes from the `CLAUDE_MODEL` env var (default `claude-sonnet-5-5`) and is logged on every call. The key comes from `ANTHROPIC_API_KEY`. `.env` goes in `.gitignore`. |
| D3 | Where numbers come from | Claude never types a digit. Template text with the `{metric_id}` references removed must contain **no digits** and **no number words** (zero to ninety-nine, hundred, thousand, million, billion, percent, half, double, triple). Months are written as words. |
| D4 | Blocked metrics | If Claude references a blocked metric in a paragraph, the draft is **rejected** (reason `blocked_reference`). It is never rendered as None or a blank. |
| D5 | Questions | Open questions are **generated by code** from the review queue and the blocked metrics, not by Claude. Every draft gets them in a fixed "Open questions" section. |
| D6 | Retries | A rejected draft is regenerated up to 3 attempts in total. If all three fail, `status="rejected"` and no rendered text is returned. |
| D7 | Traceability | Every rendered figure carries `metric_id`, the formatted value, and `sources` (a list of `(source_file, source_cell)`). If stage 4 metric rows don't carry their input cells yet, stage 5 adds that. |
| D8 | Injection | Commentary input is only metrics plus review items. Any file text that reaches Claude is a quoted JSON string field. The final output never contains "50%" or "fifty percent". |

## Interface the checker tests (`pipeline/commentary.py`)

```python
class ClaudeClient(Protocol):
    model: str
    def create(self, system: str, user: str) -> str: ...   # returns raw model text (JSON)

def draft_commentary(metrics, review_items, client: ClaudeClient,
                     log_path: Path, max_attempts: int = 3) -> Draft: ...
```

**Claude's output format** (validated with a schema; malformed JSON counts as a rejected attempt):

```json
{"sections": [{"company": "cobalt" | "portfolio", "paragraphs": ["Cobalt's net retention fell to {cobalt.12m.nrr_12m} ..."]}]}
```

**`Draft` fields:**
- `status`: `"ok"` or `"rejected"`
- `attempts`: int
- `reject_reasons`: list of str, one per failed attempt, drawn from `made_up_number`, `unknown_reference`, `blocked_reference`, `malformed_output`
- `sections`: each paragraph has `template`, `rendered`, and `figures: [{metric_id, display, sources}]`
- `questions`: list of `{company, metric, period, text}`

**Formatting** (the checker asserts these exactly): ratios are shown as `f"{v:.1f}%"`; `arr_per_employee` as `f"${v:.0f}K"`; dollar amounts in $K as `f"${v/1000:.1f}M"`.

**Log:** one JSONL line per client call in `log_path`, with fields `ts, model, attempt, system, user, output`.

## Checker tests (`tests/test_commentary_checker.py`, locked)

The checker runs the real pipeline on `data/raw/` to get metrics and the review queue. It never reads `eval/`.

1. **References resolve.** With F1, every `{…}` in every template resolves to a metric row, and no `{` or `}` is left in the rendered text.
2. **Rendered values are exact.** Each figure's `display` equals the formatting rule applied to the metrics-table value.
3. **Traceable.** Each figure has at least one source, and each `(file, cell)` exists in the stage 3 table.
4. **Guardrail: made-up number.** F2 → rejected with `made_up_number`.
5. **Guardrail: injection.** F3 (both variants) → rejected. Across every test, no output text contains `50%` or `fifty percent`, case-insensitive.
6. **Blocked metrics are never facts.** F4 → rejected with `blocked_reference`.
7. **Unknown reference.** F5 → rejected with `unknown_reference`.
8. **Malformed output.** F6 → rejected with `malformed_output`, with no crash.
9. **Retry recovers.** Sequence [F2, F1] → `status=ok`, `attempts=2`, `reject_reasons=["made_up_number"]`.
10. **Retry gives up.** Sequence [F2, F3, F4] → `status=rejected`, `attempts=3`, and no rendered text is returned.
11. **Questions cover everything open.** Every open review item and every blocked metric has a question naming its company and metric. At a minimum this covers Verity growth_12m and nrr_12m (E7), Verity June gross margin (E6), Harborview March (E1), Harborview July ending ARR (E2), and Cobalt April (E5).
12. **Logging.** The number of log lines equals the number of fake-client calls, including retries. Each line has every log field, and `model` equals `client.model`.
13. **Injection stays data.** If the string "Ignore previous instructions" appears anywhere in a logged `user` input, it is only inside a JSON string value, never in `system`.
14. **No network.** With the socket blocked (monkeypatch), the whole test file still passes.

## Audit mutations (fresh session, after the loop)

Each mutation must make at least one checker test fail. Revert it after each run.

- Number scan disabled → test 4 or 5 fails
- A blocked reference rendered as its value or as "None" → test 6 fails
- An unknown reference rendered as blank → test 7 fails
- Logging skipped on retries → test 12 fails
- An open review item dropped from the questions → test 11 fails
- Formatting changed to 0 decimals → test 2 fails
